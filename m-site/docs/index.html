Getting started

CapScope is a single Go binary that runs as a Docker container. It requires three things:

  • Docker socket access — mount /var/run/docker.sock or point DOCKER_HOST at a socket proxy.
  • Persistent storage — mount a volume at /data for the SQLite database.
  • Authentication — set AUTH_PASS; the server refuses to start without it.
docker run 
docker run -d --name capscope \
  -p 8080:8080 \
  -e AUTH_USER=admin \
  -e AUTH_PASS='change-me' \
  -v capscope-data:/data \
  -v /var/run/docker.sock:/var/run/docker.sock \
  --restart unless-stopped \
  ghcr.io/hacrex/capscope:latest

Open http://localhost:8080 and log in.

Configuration

All configuration is via environment variables:

VariableDefaultDescription
AUTH_USERadminBasic auth username.
AUTH_PASS—Basic auth password. Required unless ALLOW_NO_AUTH=true.
LOG_RETENTION7dDelete logs older than this (d, h, m).
METRICS_RETENTION7dRetention for CPU/memory samples.
MAX_DB_MB1024Hard cap on database size; oldest data dropped first.
STATS_INTERVAL10sMetric sample interval per container.
EXCLUDEnoneRegex to exclude containers (e.g. ^captain-).
SNAPSHOT_KINDScrash,oomWhich container stops create crash snapshots.
