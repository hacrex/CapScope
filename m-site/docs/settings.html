Settings

Admin-only view of the running configuration, organized by section. Secrets (passwords, tokens, keys) are omitted — boolean configured flags show whether each channel is set.

API

GET /api/settings Returns sanitized configuration grouped by section (admin only)

The response omits all secret values. Use the configured boolean on channel entries to see whether a notification channel is active.

Configuration sections

SectionWhat it covers
ServerListen address, DB path, Docker host
AuthAuth provider (local/proxy/oidc), proxy header, allow-no-auth, auth user, whether a password is set
StorageMax DB size, log/metrics/snapshot retention, redaction, initial tail, max line bytes, snapshot kinds
CollectionStats interval, access-log mode, anonymize IPs, GeoIP DB path, include/exclude filters
AlertsAlerts file path, evaluation interval, webhook/Telegram/Slack/Discord/ntfy/SMTP configuration, update check
Agent / PlatformAgent host ID, hub listen address, Docker filter, OTLP listen/path, pipelines file, archive bucket/prefix, retention hot days

  "alerts": {
    "alerts_file": "/data/alerts.json",
    "alerts_interval": "1m",
    "webhook": { "url": "", "configured": false },
    "telegram": { "configured": false },

    "discord": { "url": "", "configured": false },
    "ntfy": { "url": "", "configured": false },

UI: Settings are also available in the CapScope UI under the Settings tab — the same /api/settings data rendered as cards.
