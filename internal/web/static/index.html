Built for container forensics & live observability

One binary, one volume, no external database. Persistent history, crash evidence, and alerting — read-only by design.

🐛

Crash snapshots

Automatic snapshots on OOM, exit, or health-check failure — with exit code, last log lines, memory trend, and rule-based summary.

🔍

Semantic log clustering

Recurring log lines are grouped by template fingerprint, so you see patterns instead of noise — dashboards stay clean at scale.

🔒

Immutable evidence

Tamper-evident hash chain over every log row. Verify integrity with /api/evidence/verify — ideal for regulated environments.

🤖

Local-first crash explainer

MCP-powered crash analysis via local Ollama LLM with rule-based fallback — AI incident analysis that never leaves your host.

🔗

Code-to-log correlation

Git commit SHA captured from Docker image labels. Trace a crash back to the exact commit that introduced it.

📧

SMTP alerts & digest

Email notifications with immediate or digest mode. Combine with webhook, Slack, Discord, Telegram, ntfy, PagerDuty, and Opsgenie channels.

☸️

Helm chart for Kubernetes

Official Helm chart with RBAC, PVC for SQLite, mTLS agent hub, and multi-host aggregation — deploy CapScope anywhere.

📊

Log forwarding

Stream logs to Loki or Elasticsearch for long-term retention beyond CapScope's SQLite cap.

💰

FinOps cost attribution

Per-app CPU/memory cost estimates, right-sizing recommendations, and carbon footprint — know what your containers cost.

🚨

On-call war room

Unified view of anomalies and recent crashes — page the right person faster with a single operational dashboard.

💡

Self-healing advice

Crash-specific remediation suggestions — OOM, segfault, restart loop, or bad entrypoint — with copyable fix commands.

📦

Sneakernet bundle

Export a self-contained HTML incident bundle — no server needed to review crash evidence on an air-gapped machine.
