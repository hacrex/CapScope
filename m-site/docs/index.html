What CapScope does

AreaWhat you get
Live logs Per-app sidebar, virtual-scrolled live tail over SSE, pause/follow, load older, split view for up to 4 replicas side by side.
Search history FTS5 full-text search over persisted logs, regex mode, or raw SQL via /api/sql; filter by level, stream, and replica.
History after redeploy Logs and CPU/memory samples persist in SQLite with age and size retention; search an app's logs long after its container is gone.
Crash snapshots Exit code, OOM flag, restart count, uptime, last N log lines, last N metric samples, rule-based summary, Markdown export.
Restart-loop detection Counts deaths per container in a sliding window; flags loops with a ↻ badge in the UI.
Access-log dashboard GoAccess-style panels from your reverse proxy's access logs: status codes, top paths, client IPs, referrers, hits/errors timeline, CSV export.
Deploy markers Record deploys from CI or the UI; markers appear on CPU/memory charts and inline in the log timeline.
Alerts Dead-man, restart loop, metric threshold, and log-pattern rules; webhook, Telegram, Slack, and Discord channels.
Secret redaction Masks JWTs, bearer tokens, password=/token= values, URL credentials, AWS keys, and PEM keys before storage.
