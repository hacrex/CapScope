Distributed tracing

CapScope ingests OTLP traces at /v1/traces and renders them as a trace list with an SVG span waterfall diagram — no Jaeger, Tempo or external tracing stack required.

OTLP trace ingestion

CapScope accepts OTLP HTTP payloads at /v1/traces (and /v1/logs, /v1/metrics) on a separate listen address configured with OTEL_LISTEN. Resource attributes (service.name, host.name, container.id) are mapped to CapScope app, host_id and container_id so traces line up with your logs and metrics.

Auth: OTLP endpoints honor the same session token or proxy header as the REST API. Viewer app-scoping applies to trace queries — viewers only see traces for their assigned applications.

Trace list

GET /api/traces?service=…&min_duration=…&error=true returns a Dapper-style trace list grouped by trace_id. Each entry shows:

FieldMeaning
trace_idTrace identifier — click to open the waterfall
serviceService name from OTLP resource attributes
nameSpan operation name
start_tsEarliest span start time in the trace
duration_msLongest span duration in the trace
span_countNumber of spans in the trace
statusok or error — any error span marks the whole trace

Trace waterfall

GET /api/traces/{trace_id} returns all spans of a trace. The UI renders them as an SVG waterfall:

  • One lane per service — spans are grouped by service so you can see cross-service boundaries at a glance
  • Bar width = duration — each span's bar is proportional to its duration
  • Color = status — green for ok, red for error
  • Click a span to see its kind (server, client, producer, consumer), start/duration and parent span

Trace-to-log correlation

When a log line carries a trace_id (from OpenTelemetry severityText/severityNumber or Pino numeric levels), CapScope indexes it so you can jump from a log line to its trace — and from a trace back to the logs that produced it.

Storage

Spans live in the same hot SQLite database as logs and metrics, in a spans table indexed on trace_id, service and parent_span_id. Trace retention shares the log retention window, so old traces are pruned with old logs.
