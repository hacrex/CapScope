Container logs that survive redeploys.

CapScope is self-hosted container observability in one binary. Persistent logs, crash snapshots, CPU/memory history, and an access-log dashboard — no Prometheus stack, no external database.

Everything you need after a container dies

Live tails are great. History is better. Crash forensics are best.

💾

Persistent Logs

Logs stored in SQLite with FTS5 search. Search history long after a redeploy removes the container.

💥

Crash Snapshots

Auto-saved on OOM or non-zero exit. Exit code, memory trend, last log lines, plain-language summary.

📊

Metrics History

CPU and memory samples persisted for 15 minutes to 7 days, per app or replica.

🔁

Restart-Loop Detection

Flags containers dying in a loop with a ↻ badge. Know when an app is crash-looping.

🌐

Access Log Dashboard

GoAccess-style panels from your reverse proxy: status codes, top paths, client IPs, CSV export.

🚀

Deploy Markers

Correlate crashes and metric spikes with the release that preceded them.

One binary. One volume.

1

Run it

One Docker container with /var/run/docker.sock mounted and a /data volume.

2

Watch it

CapScope follows logs and stats for every container, redacting secrets before storage.

3

Sleep better

When a container dies at 3 AM, open the Crashes tab and see exactly what happened.

Quick start

docker run -d --name capscope \
  -p 8080:8080 \
  -e AUTH_USER=admin \
  -e AUTH_PASS=change-me \
  -v capscope-data:/data \
  -v /var/run/docker.sock:/var/run/docker.sock \
  --restart unless-stopped \
  ghcr.io/hacrex/capscope:latest
