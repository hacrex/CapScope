HTTP API

Base URL: http://<host>:8080. All endpoints except /healthz require Basic auth when AUTH_PASS is set.

Authentication

Use the Authorization: Basic <base64(user:pass)> header on every request. Example:

curl -u admin:change-me http://localhost:8080/api/containers

Health

GET
/healthz

Returns ok. No authentication required.

Containers & apps

GET
/api/containers

Returns running containers being followed.

{"containers":[{"id":"...","name":"srv-captain--shop.1.x","app":"shop","replica":"1","image":"shop:1.4","started":1793158700000,"cpu":12.5,"mem":104857600,"mem_limit":536870912,"sample_ts":1793158700000}]}
GET
/api/apps

Returns apps known from history with a one-hour error and warning count.

{"apps":[{"app":"shop","containers":1,"last_seen":1793158700437,"errors_1h":8,"warns_1h":14}]}

Logs

GET
/api/logs

Returns log rows oldest first.

ParamDescription
appFilter by app name.
containerFilter by container name or id prefix.
qSearch text (case-insensitive, FTS5 prefix index).
regex1 treats q as a case-insensitive regular expression.
levelComma list: error, warn, info, debug.
streamstdout or stderr.
sinceRelative (15m, 2h, 1d) or epoch ms.
limitDefault 500, max 5000.
GET
/api/logs/stream

Server-Sent Events stream of new log rows matching the same filters.

GET
/api/logs/export

Streams matching rows as CSV (capscope-logs.csv), up to 200,000 lines.

Access logs

GET
/api/access?range=1h

Returns aggregated access-log dashboard data: totals, status codes, top paths/IPs/referrers, hits-and-errors timeline.

{"totals":{"requests":900,"client_err":41,"server_err":9,"unique_ips":3,"bytes":88401},"codes":[{"code":200,"n":600}],"paths":[{"key":"/api/items","hits":212,"bytes":9901,"errors":3}],"timeline":[{"ts":1793157492000,"hits":30,"errors":1,"bytes":2955}]}
GET
/api/access/export

Streams raw parsed rows as CSV (capscope-access.csv).

Metrics

GET
/api/metrics?app=shop&range=1h

Returns bucketed CPU/memory points. For an app, values are summed across replicas.

{"bucket_ms":12000,"points":[{"ts":1793157492000,"cpu":10,"mem":104857600,"mem_limit":536870912}]}

Crash snapshots

GET
/api/snapshots?app=shop&limit=100

Returns light snapshot rows (no logs/metrics), newest first.

GET
/api/snapshots/{id}

Returns the full snapshot: metadata, summary, logs, metrics, and trimmed inspect object.

GET
/api/snapshots/{id}/export

Returns a Markdown crash report for incident handoff.

SQL queries

GET
/api/sql?query=

Runs one ad-hoc read statement (SELECT or WITH … SELECT) against stored tables.

SELECT app, level, count(*) AS n
FROM logs
WHERE ts > (unixepoch('now') - 3600) * 1000000000
GROUP BY app, level
ORDER BY n DESC

Alerts

GET
/api/alerts

Returns alert firing history, newest first.

GET
/api/alerts/rules

Returns armed alert configuration.

POST
/api/alerts/test

Sends a test message through every configured channel.

Deploys

POST
/api/deploys

Records a deploy marker. Body: {app, version, note?, ts?}.

{"app":"shop","version":"v1.4","note":"hotfix"}
GET
/api/deploys

Returns deploy markers newest first.
