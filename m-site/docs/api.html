HTTP API

All endpoints except /healthz require Basic auth when AUTH_PASS is set. Responses are JSON unless noted. Timestamps named ts are Unix milliseconds.

Base URL: http://<host>:8080

Authentication

Use the Authorization: Basic <base64(user:pass)> header on every request.

Health

GET /healthz

Returns ok.

Containers & apps

GET /api/containers

Returns running containers being followed.

{"containers":[{"id":"...","name":"srv-captain--shop.1.x","app":"shop","replica":"1","image":"shop:1.4","started":1793158700000,"cpu":12.5,"mem":104857600,"mem_limit":536870912,"sample_ts":1793158700000}]}
GET /api/apps

Returns apps known from history with a one-hour error and warning count.

{"apps":[{"app":"shop","containers":1,"last_seen":1793158700437,"errors_1h":8,"warns_1h":14}]}

Logs

GET /api/logs

Returns rows oldest first.

ParamMeaning
appApp name
containerContainer name or id prefix
qSearch text. Case-insensitive. Uses an FTS5 token/prefix index as a fast path; falls back to a LIKE substring match.
regex1 treats q as a case-insensitive regular expression.
levelComma list of error, warn, info, debug
streamstdout or stderr
sinceRelative (15m, 2h, 1d) or epoch milliseconds
untilEpoch milliseconds
limitDefault 500, max 5000

Row shape: {id, ts, container_id, container, app, stream, level, line}. stream is o for stdout and e for stderr.

GET /api/logs/stream

Server-Sent Events stream of new rows matching the same filters.

GET /api/logs/export

Streams matching rows as CSV (capscope-logs.csv), up to 200,000 lines.

Access logs

GET /api/access?range=1h

Returns aggregated dashboard data: totals, status-code distribution, top paths/IPs/referrers, hits-and-errors timeline.

{"since_ms":...,"until_ms":0,"bucket_ms":12000,"totals":{"requests":900,"client_err":41,"server_err":9,"unique_ips":3,"bytes":88401},"codes":[{"code":200,"n":600}],"paths":[{"key":"/api/items","hits":212,"bytes":9901,"errors":3}],"ips":[{"key":"203.0.113.0","hits":400,"bytes":41000,"errors":2}],"refs":[{"key":"https://google.com/","hits":12,"errors":0}],"timeline":[{"ts":1793157492000,"hits":30,"errors":1,"bytes":2955}]}
GET /api/access/export

Streams raw parsed rows as CSV (capscope-access.csv). Default range 24 h, 100,000 rows max.

SQL queries

GET /api/sql?query=

Runs one ad-hoc read statement against the stored tables. SELECT or WITH … SELECT only.

SELECT app, level, count(*) AS n
FROM logs
WHERE ts > (unixepoch('now') - 3600) * 1000000000
GROUP BY app, level HAVING n > 5
ORDER BY n DESC

Tables: logs, metrics, containers, snapshots (and logs_fts for MATCH joins).

Metrics

GET /api/metrics?app=shop&range=1h

Returns bucketed points (about 300 per range, minimum bucket 5 s). For an app, CPU and memory are summed across replicas.

{"bucket_ms":12000,"points":[{"ts":1793157492000,"cpu":10,"mem":104857600,"mem_limit":536870912,"net_rx":0,"net_tx":0,"blk_r":0,"blk_w":0,"pids":0}]}

Crash snapshots

GET /api/snapshots?app=shop&limit=100

Returns light rows (no logs or metrics), newest first.

GET /api/snapshots/{id}

Returns the full snapshot: metadata, summary, logs, metrics and a trimmed inspect object.

GET /api/snapshots/{id}/export

Returns a Markdown crash report suitable for pasting into an incident channel.

Snapshot kind is one of oom, crash, killed, clean_exit.

Alerts

GET /api/alerts?app=shop&limit=100

Returns the firing history, newest first.

GET /api/alerts/rules

Returns the armed configuration without secrets.

POST /api/alerts/test

Sends a test message through every configured channel.

Deploys

POST /api/deploys

Records a deploy marker. Body: {app, version, note?, ts?}. app is required.

{"id":1,"ts":1793158700000,"app":"shop","version":"v1.4","note":"hotfix"}
GET /api/deploys?app=shop

Returns markers newest first.
